# 教程截图目录

请将教程截图上传到这个目录下。

推荐命名方式：

- `okx-web-01.png`
- `okx-web-02.png`
- `okx-web-03.png`
- `okx-app-01.png`
- `okx-app-02.png`
- `okx-app-03.png`
- `config-setup-01.png`
- `config-setup-02.png`

用途建议：

- `okx-web-*`：OKX 网页版创建 API Key 教程
- `okx-app-*`：OKX 手机 App 创建 API Key 教程
- `config-setup-*`：本地 `~/.okx/config.toml` 配置教程

上传完成后，可以在以下文档里引用这些图片：

- `docs/okx-api-setup.md`
- `docs/config-setup.md`
